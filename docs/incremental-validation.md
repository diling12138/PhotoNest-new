# 0.7.0 增量索引验证记录

日期：2026-11-09。

## 本次功能

- 初次完整发现，随后先登记文件，再补图片信息和内容哈希；变化文件优先处理。
- 持久保存应用媒体根、目录身份、文件身份、USN 游标及待处理任务。
- NTFS 日志可用时，重新启动补读离线期间的变更；运行中递归监听媒体根目录。
- 日志断档时核验受影响范围；接口不可用时核验一次并降级目录监听，避免持续全盘扫描。
- 游标与待处理路径在同一事务保存；取消、监听溢出、临时 I/O 失败及目录恢复都有补账路径。
- QQ、微信、Steam 按较上层应用媒体目录归类，并定向发现用户数据分支及 Steam 自定义截图位置。
- 图片、GIF、常见视频入库；GIF 播放/暂停，视频按需生成封面和调用系统播放器。
- 关闭窗口隐藏至托盘；托盘支持唤回、暂停同步和退出。同一照片库重复启动唤回已有实例。

## 使用边界

升级首次需要建立一次基线，之后才能使用保存的日志位置。没有可读日志的卷会在启动时进行范围核验。专有/加密应用缓存不解密，视频暂不做画面语义识别，也不提供内嵌播放器。退出进程后不再监听，下一次启动依赖日志或范围核验补齐。
